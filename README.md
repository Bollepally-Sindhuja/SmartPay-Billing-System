
# SmartPay Utility Billing System

## Project Description

SmartPay is a Java-based utility billing system developed to calculate electricity and water bills for customers. It applies slab-based pricing, validates user input, and generates a digital receipt.

## Features

* Calculates **Electricity and Water Bills**
* Supports **slab-based pricing system**
* Handles **decimal unit inputs**
* Performs **input validation**
* Includes **exception handling**
* Generates a **formatted digital receipt**
* Allows **multiple customer entries**

## Concepts Used

* Java OOP (Object-Oriented Programming)
* Interface & Abstraction
* Polymorphism
* Exception Handling
* Loops and Conditional Statements
* User Input Handling (Scanner)

## How It Works

1. User enters customer name
2. Inputs previous and current meter readings
3. System calculates units consumed
4. Applies slab rates for electricity and water
5. Adds tax and generates final bill
